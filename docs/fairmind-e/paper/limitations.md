# Limitations

- The current evaluation is hand-labeled and small.
- The fixture set is synthetic and should not be presented as production measurement.
- Impact thresholds are provisional and require calibration before strong empirical claims.
- The evaluator tests gate consistency, not measurement accuracy.
- The method does not verify supplier claims by itself.
- Exception validity is structurally checked; organizational approval quality is outside this slice.
- The UI and API demonstrate workflow feasibility, not user-study effectiveness.

These limits are acceptable for an early systems paper draft if claims stay focused on machine-readable gate behavior.
