FairMind is deployed as separate application surfaces.

| Surface | Intended host | App |
| --- | --- | --- |
| Marketing | `fairmind.xyz` | `apps/website` |
| Product | `app.fairmind.xyz` | `apps/frontend` |
| Documentation | `docs.fairmind.xyz` | `apps/docs` |
| API | deployment-specific | `apps/backend` |

## Build the docs

```bash
cd apps/docs
npm install
npm run build
```

The docs Netlify configuration runs `npm run build`, publishes `.next`, and sets `SITE_URL=https://docs.fairmind.xyz`.

## Release gate

Before calling a docs release deployed:

1. Build the app successfully.
2. Open every navigation route.
3. Verify desktop and mobile layouts.
4. Test search, 404s, canonical metadata, sitemap, robots, and cross-links.
5. Deploy the intended commit to the configured Netlify site.
6. Verify custom-domain attachment, DNS, TLS, and representative public routes.
