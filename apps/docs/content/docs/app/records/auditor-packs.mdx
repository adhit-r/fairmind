## What it is for

A pack is a frozen snapshot for an auditor: the evidence, release decisions and framework coverage for the systems and frameworks you choose, with a hash that shows it was not changed. The full model, including the API, is in [inspection packs](../../journeys/inspection-packs.mdx).

The heading counts your packs and how many are currently shared. A pack is a snapshot, so evidence added later is not in it. Build a new one to capture it.

## How to use it

1. Choose **Build a pack**.
2. Enter a **Title**, tick one or more **Frameworks** and one or more **AI systems**. **Build pack** stays disabled until all three are filled. If no system is registered, the dialog tells you to register one first.
3. On a pack card, choose **Open** to see its contents.
4. Choose **Share a link**. A **Read-only link** dialog shows the address once. Use **Copy link** now: it cannot be read again. Anyone holding it can read the pack until it expires or you stop sharing.
5. Choose **Stop sharing** to end access. The button appears only while a link is live.
6. Choose **Download** to save the pack as a file.
7. Choose **How to verify a pack** to see the offline check: `fairmind verify pack.json`. It recomputes the pack hash and each evidence chain without calling FairMind, and reports anything that changed or went missing.

Opening this page with `?framework=<key>` pre-opens the builder with that framework ticked and a title filled in.

## What's on the page

Each card shows up to three framework tokens, the title, the systems included, a sharing state (**Shared, expires** a date, **Link expired** a date, or **Not shared**), the first 12 characters of the manifest hash, and who built it and when.

If the API fails, the page shows "The packs could not load" with **Try again**. With no packs it shows "No packs built yet".
