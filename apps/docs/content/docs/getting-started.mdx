# Getting started with the P0 control plane

FairMind P0 is an internal, default-off assurance control plane. It records and
checks the identity, scope, trust, review, freshness, and decision history of
evaluation evidence. It is not a packaged evaluator, a production monitoring
service, a certification product, or an automatic enforcement system.

Read the [release boundary](./release-boundary) before enabling any Assurance V2
route in an approved internal environment.

## Local development

From the repository root, use the app-specific commands:

```bash
cd apps/backend
uv run python -m uvicorn api.main:app --reload --port 8000
```

```bash
cd apps/frontend
npm run dev
```

```bash
cd apps/docs
npm run dev
```

The backend listens on `http://localhost:8000`, the dashboard on
`http://localhost:1111`, and this docs app on `http://localhost:3333`.

## What is enabled by default

All Assurance V2 settings default to `false`, including the master setting
`assurance_v2_enabled` and every child capability setting. A disabled capability
is not a partial success: its router is not mounted by the main application.

Do not enable these settings from this guide. Activation requires the approved
environment, migrations, tenant data, trust-root administration, permissions,
and release gates for the capability in question.

## Dashboard preview

The dashboard has an Assurance V2 evidence-trust detail surface. It is
read-only, scope-bound, and separately default-off. It shows only a validated
V2 run response; unavailable or denied data is not replaced with a legacy
record or fixture. The dashboard route is an internal preview, not proof that
the backend capability is available in an environment.
