<Status state="shipped" />

This guide gets you a FairMind server, an API key, and a first verdict on one AI system. It takes about ten minutes on a running server.

<Steps>
<Step>
### Get a FairMind server

<Tabs groupId="server" items={['Hosted', 'Run locally']} persist>
<Tab value="Hosted">

Sign in at [app.fairmind.xyz](https://app.fairmind.xyz). New accounts wait for an administrator to approve them.

</Tab>
<Tab value="Run locally">

You need Python 3.11 or later, [`uv`](https://docs.astral.sh/uv/), Node.js and a PostgreSQL database.

```bash title="Terminal 1: API"
cd apps/backend
uv sync
uv run python scripts/setup_db.py      # creates the schema
uv run python -m uvicorn api.main:app --reload --port 8000
```

```bash title="Terminal 2: dashboard"
cd apps/frontend
npm install
NEXT_PUBLIC_API_URL=http://localhost:8000 npm run dev   # http://localhost:1111
```

`curl http://localhost:8000/health/ready` should answer before you go on. [Self-host](/docs/self-host/deployment) covers production settings.

</Tab>
</Tabs>
</Step>

<Step>
### Register a system

In the dashboard, open **Onboard** and record the system's name, owner, risk tier and the frameworks that apply. [Register a system](/docs/journeys/register-system) explains each field.
</Step>

<Step>
### Create an API key

While signed in, create a key with `POST /api/v1/auth/api-keys` and a name. Keys are valid for 365 days and act as the user who created them, in that user's organisations.

```bash
export FAIRMIND_API_URL=https://app.fairmind.xyz   # or http://localhost:8000
export FAIRMIND_API_KEY=...                        # never commit it
```

<Callout type="info">There is no API key page in Settings yet; create keys through the API.</Callout>
</Step>

<Step>
### Install the SDK

<Tabs groupId="pkg" items={['pip', 'uv']} persist>
<Tab value="pip">
```bash
pip install "git+https://github.com/adhit-r/fairmind.git#subdirectory=apps/sdk"
```
</Tab>
<Tab value="uv">
```bash
uv add "git+https://github.com/adhit-r/fairmind.git#subdirectory=apps/sdk"
```
</Tab>
</Tabs>
</Step>

<Step>
### Read the release gate

```python title="first_verdict.py"
from fairmind import FairMind

fm = FairMind()  # reads FAIRMIND_API_URL and FAIRMIND_API_KEY

system = fm.systems()[0]["id"]
gate = fm.gate(system)

print(gate["verdict"], gate["confidence"])   # go, conditional_go or no_go
for check in gate["checks"]:
    print(check["label"], check["state"])    # proven, attested or open
```

A new system reads `no_go` with every check open. That is expected: nothing has been measured yet.
</Step>

<Step>
### Measure something

Find an evaluation FairMind can run, then run it. Results are stored as measured evidence on the system and the gate updates.

```python
for e in fm.evaluations(query="prompt injection"):
    if e["runnable"]:          # the others accept evidence from your own tools
        print(e["id"], e["name"])

run = fm.run_evaluation(system, "EV-SEC-01")   # Direct prompt injection, a behaviour test
print(run["status"], run["summary"])           # passed, failed or insufficient
```

A behaviour test calls your system and has your organisation's model judge the answers, so it needs two settings first: an **AI provider** in organisation settings, and **how FairMind calls this system** on the system's page. It runs as a background job; the SDK waits for it. Each evaluation takes different inputs, and `fm.evaluation_engine(id)` lists them. [Govern your first agent](/docs/journeys/govern-your-first-agent) walks through a full run.
</Step>
</Steps>
