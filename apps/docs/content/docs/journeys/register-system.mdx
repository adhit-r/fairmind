Use system registration before running an assessment or recording evidence.

## Before you begin

Prepare the system name, accountable owner, intended use, risk tier, and the governance frameworks relevant to the review.

## Register the system

1. Open **Inventory › AI systems** and press **Register systems**.
2. Enter the system name and owner, or upload a CSV to register several.
3. Select a risk tier based on the impact of incorrect or harmful behavior.
4. Select the governance frameworks that will organize requirements and evidence mappings.
5. Open the new system file and press **Confirm tier and rules**.

## Choose the next step

The system file lists what the system needs next under **What it needs**. Run a test, record evidence or attest from there. For a fairness check on tabular data, use **Run a fairness test**; for energy and carbon, see [Environmental evaluation](/docs/journeys/environmental-evaluation).

## What registration proves

Registration proves that a governance record exists. It does not prove that the underlying model, dataset, or deployment has been independently verified.
