---
title: What is FairMind
description: An open-source AI assurance workbench for models and agents. It turns governance frameworks into controls, collects evaluation evidence, and gates releases.
---

<Status state="partial">Alpha, November 2026. The main path works end to end; see [Status and limits](/docs/get-started/status-and-limits).</Status>

FairMind keeps an AI system, its tests, evidence, risks, remediation and approvals in one reviewable record. It answers one question for a release: **may this system ship, and what is the evidence?**

One rule runs through the product: an evaluation result is evidence for a decision, never the decision itself. A person decides.

## The lifecycle

| Stage | Question | Where |
| --- | --- | --- |
| **Onboard** | Which system are we governing, and under which frameworks? | [Register a system](/docs/journeys/register-system) |
| **Assess** | What was tested, how, and against which threshold? | [Govern your first agent](/docs/journeys/govern-your-first-agent) |
| **Govern** | Which evidence and risks bear on each control? | [Review evidence](/docs/journeys/evidence-review) |
| **Remediate** | What must change, who owns it, and did the retest pass? | [Fix and retest](/docs/journeys/remediation-retest) |
| **Operate** | What changed after release? | [Scheduled monitoring](/docs/journeys/scheduled-monitoring) |

## What you can do today

- **Evaluate models and agents.** All 109 catalogue evaluations run in FairMind: on uploaded files, as behaviour tests against your live system, as configuration audits of your agent platform, or on results from your own sandbox, drills and detectors.
- **Map to frameworks.** Read the release gate clause by clause, led by the EU AI Act, ISO/IEC 42001, the NIST AI RMF and the RBI FREE-AI framework. Catalogue evaluations also map to AIUC-1 requirements.
- **Gate a release.** Five checks give `go`, `conditional_go` or `no_go`. Failing blocking policy rules force `no_go`.
- **Hand an auditor a verifiable pack.** Export an inspection pack, share a read-only link, and verify it offline with `fairmind verify`.
- **Work from code or an agent.** The [Python SDK](/docs/build/python-sdk), [CLI](/docs/build/cli), GitHub Action and [MCP server](/docs/build/mcp-server) use the same API with an API key.

## What FairMind is not

- Not a certification. It produces no compliance certificate, automatic approval or "verified" badge.
- Not a runtime guardrail. It assesses systems; it does not sit in the request path.
- Not a sandbox. Evaluation engines run inside the backend; uploaded model files are inspected, never executed.
