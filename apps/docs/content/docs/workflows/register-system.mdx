## Before you begin

Prepare the system name, accountable owner, intended use, risk tier, and the governance frameworks relevant to the review.

## Register the system

1. Open **Systems > Register System**.
2. Record the system and workspace identity.
3. Select a risk tier based on the impact of incorrect or harmful behavior.
4. Select the governance frameworks that will organize requirements and evidence mappings.
5. Review the requirements shown by the workflow.
6. Confirm the record and enter the lifecycle.

## Choose the next step

The onboarding interface can offer a tabular bias scan. Skip that branch in the current release because the active evaluator endpoint is unavailable. Continue to the system dashboard or use the validated environmental path.

## What registration proves

Registration proves that a governance record exists. It does not prove that the underlying model, dataset, or deployment has been independently verified.
