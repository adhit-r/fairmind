## Request review

1. Confirm the selected system.
2. Review open risks, missing evidence, and remediation status.
3. Submit the approval request with a clear decision scope.
4. Record the reviewer, decision, rationale, and any conditions.

Approval state is a recorded workflow decision. It is not a legal certification.

## Generate a snapshot

The active report route persists a JSON snapshot containing the system record, risks, evidence, remediation, and approvals.

Use a snapshot when you need to show the state reviewed for a release meeting or audit checkpoint.

<Callout type="warn" title="Export boundary">
The active governance report route does not implement the frontend-declared export endpoint and does not produce a signed PDF or DOCX assurance package. Document the current output as a persisted audit-report snapshot.
</Callout>
